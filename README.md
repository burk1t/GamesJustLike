# GamesJustLike

Интернет-магазин компьютерных игр с системой персональных рекомендаций.

## О проекте

GamesJustLike — веб-приложение, предназначенное для просмотра каталога компьютерных игр и формирования персональных рекомендаций на основе предпочтений и действий пользователей.

## Основные возможности

- Авторизация пользователей.
- Каталог компьютерных игр.
- Хранение пользовательских предпочтений.
- Регистрация просмотров, добавлений в корзину и покупок.
- Персональное ранжирование игр.
- Групповые рекомендации.
- Диагностика и тестирование алгоритма.

## Технологии

- PHP
- SQLite
- HTML
- CSS
- JavaScript
- XAMPP / Apache

## Запуск проекта

1. Установить XAMPP.
2. Поместить папку проекта в `C:\xampp\htdocs`.
3. Запустить Apache.
4. Открыть сайт через локальный адрес `http://localhost/GamesJustLike-site/`.

## Назначение

Учебный проект, разработанный в рамках практической работы по реализации системы персональных рекомендаций интернет-магазина.
